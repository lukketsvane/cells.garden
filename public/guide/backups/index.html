Keep a copy of your garden

Download your projects before moving devices, clearing browser storage or trying an import. A saved copy is useful whether you work locally or use account sync.

Download a backup

  1. Open the garden you want to copy.
  2. Open the garden menu and choose Export or import.
  3. Under Download a copy, choose Download .zip.
  4. Keep the downloaded file somewhere you can find outside the app.

The archive contains plants and settings, with one Markdown file per plant. Give your backup a dated filename so you can tell copies apart. If your installation has no account menu, use the garden’s export/import button.

Read the Markdown files

Unzip a copy of the archive to inspect its files. Markdown is a text format you can open in an editor, including Obsidian. The export is a portable copy; editing an exported file does not automatically update the live garden.

Inside the Obsidian plugin, garden data is normally saved in the plugin’s data file. It is not automatically written into your regular vault notes.

Import a copy

  1. First download a backup of the garden currently open, especially if it contains work you want to keep.
  2. Open Export or import.
  3. Drop the garden ZIP, a folder or a compatible Markdown file into the import area. You can also choose Files… or Folder….
  4. Read the import summary before applying it.
  5. Choose Merge or Replace deliberately.

Merge versus Replace

ChoiceEffect
MergeUpdates matching plants and keeps the other plants already in the garden. Matching plants can change.
ReplaceDiscards the open garden’s existing contents and replaces them with the import.

Replace is destructive. Keep a backup first. If a garden is shared or synced, its edits can also affect the other people or devices using it.

Backup and sync solve different problems

Sync carries changes between signed-in installations. It is not a version-history service or a substitute for a saved backup. Download a separate copy before bulk changes or imports.

Local gardens can be lost if you clear site storage, remove an extension or delete plugin data. Do not clear storage as a troubleshooting step until you have saved a copy.

Moving from the original Garden Cells plugin

In Obsidian, use Import this vault’s garden to bring in plants from the original Garden-Cells/ folder. Turn the original plugin off before enabling cells.garden so the two sets of styles do not conflict. See the Obsidian setup guide.
